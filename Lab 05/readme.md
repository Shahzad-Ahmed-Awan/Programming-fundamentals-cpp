## ✨ Lab Overview

This lab demonstrates foundational decision-making in C++ using both independent `if` statements and the structured `if-else` construct.

**Key Concepts Demonstrated:**

* **Conditional Statements:** `if` and `if-else` logic.
* **Logical Operators:** Combining conditions using `&&` (AND) and `||` (OR).
* **I/O Formatting:** Use of `setw`, `setfill`, and `setprecision`.

## 🔍 LAB-5 TASK DETAILS

This table provides a simple summary of the objective, key concepts, and expected output for all eight programs in `lab-5.cpp`.

| Program Name | Objective/Description | Key Concepts | Required Output/Format |
| :--- | :--- | :--- | :--- |
| **Program 1 (Positive Number)** | Check if a user-input number is positive. | Simple `if` statement | Confirmation message if the number is positive. |
| **Program 2 (Even Number)** | Check if a user-input number is even. | Simple `if`, Modulus Operator (`%`) | Confirmation message if the number is even. |
| **Program 3 (Largest Number)** | Find and display the largest of three user-input numbers. | Multiple `if` statements, Logical AND (`&&`) | A single line stating which number is the largest. |
| **Program 4 (Grade Calculation)** | Determine a letter grade based on user-input marks (0-100). | Multiple `if` statements, Range checking | Displays the calculated grade (e.g., "Your grade is: A") or a "fail" message. |
| **Program 5 (Traffic Signal)** | Give driving instruction based on a user-input signal color (R, G, Y). | Multiple `if` statements, Logical OR (`||`) | Displays the instruction: **Stop**, **Go**, or **Slow Down**. |
| **Program 6 (PAY ROLE MANAGEMENT)** | Calculate Net Salary based on employee Grade, Service, Bonus, and Tax. | Multiple `if` statements, Constants | A detailed, formatted "Salary Slip" showing all financial deductions and totals. |
| **Program 7 (IF ELSE Balance withdrawal)** | Simulate an ATM withdrawal and check for sufficient funds. | `if-else` statement, `setprecision(2)` | **Success:** Remaining balance formatted to 2 decimals. **Failure:** "Insufficient balance." |
| **Program 8 (Loan Eligibility)** | Determine eligibility for a loan based on salary and experience. | `if-else` statement, Logical AND/OR | A single line stating **"Eligible for loan"** or **"Not eligible for loan."** |

## 🚀 How to Run the Code

To compile and execute this lab file, you will need a C++ compiler (e.g., `g++`).

1.  **Navigate to the Directory:**
    ```bash
    cd path/to/lab-5
    ```

2.  **Compile the File:**

    (Ensure the program you want to run is **uncommented** in the `.cpp` file.)

    ```bash

    ```

3.  **Execute the Program:**

