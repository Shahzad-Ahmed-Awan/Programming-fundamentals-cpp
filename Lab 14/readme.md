## ✨ Lab Overview

This lab demonstrates how to create structured, complex data records (`struct`) and manage collections of these records efficiently in memory using dynamic allocation.

**Key Concepts Demonstrated:**

* **`struct` Definition:** Creating a user-defined data type to group related variables.
* **Member Functions:** Defining functions inside a structure.
* **Array of Structures:** Storing multiple records of the same structure type.
* **Dynamic Memory Allocation:** Using `new` to allocate memory for structures at runtime.
* **Arrow Operator (`->`):** Accessing structure members through a pointer.
* **Pointer Arithmetic:** Iterating through a dynamic array of structures using pointers.
