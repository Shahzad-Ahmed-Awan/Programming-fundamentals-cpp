## ✨ Lab Overview

This lab demonstrates how to use the `for` loop for tasks involving a known number of iterations, including simple counting, mathematical calculations, and printing complex patterns.

**Key Concepts Demonstrated:**

* **`for` Loop:** The primary iteration control structure.
* **Accumulators:** Variables used to track totals (e.g., Summation, Factorial).
* **Nested `for` Loops:** Using one `for` loop inside another to generate **2D patterns**.
* **Input Validation:** Checking for invalid input (e.g., negative numbers for factorial).

## 🔍 LAB-10 TASK DETAILS

This table provides a simple summary of the objective, key concepts, and expected outcome for all five programs/tasks in `Lab_10_For Loop.cpp`.

| Program Name | Objective/Description | Key Concepts | Required Output/Format |
| :--- | :--- | :--- | :--- |
| **Program 1 (Number Displayer)** | Print all integers starting from 1 up to a user-specified number (N). | `for` Loop, User Input | A single-column list of numbers, right-aligned and formatted. |
| **Program 2 (Summation)** | Calculate the sum of all integers from 1 to 100. | `for` Loop, **Accumulator** | A single line displaying the final sum (5050). |
| **Pattern 1 (Square)** | Print a fixed 5x5 square pattern of asterisks. | **Nested `for` Loops** | A grid of `*` characters (5 rows and 5 columns). |
| **Pattern 2 (Triangle)** | Print a decreasing right-aligned triangle pattern of asterisks. | **Nested `for` Loops**, Loop dependency | A triangle pattern where each successive row has one fewer `*`. |
| **Program 5 (Factorial)** | Calculate the factorial of a user-input number (N!). | `for` Loop, **Accumulator**, Input Validation (`if`) | Displays the result (e.g., `5! = 120`) or an error for negative input. |
