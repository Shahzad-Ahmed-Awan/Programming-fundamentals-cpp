## ✨ Lab Overview

This lab demonstrates how to use `while` and `do-while` loops for counter-controlled and sentinel-controlled repetition.

**Key Concepts Demonstrated:**

* **`while` Loop:** Used when the condition should be checked *before* the loop body executes.
* **`do-while` Loop:** Used for tasks like menu systems where the loop body must execute *at least once*.
* **Loop Control Variables:** Initializing, testing, and updating variables to manage loop execution.
* **Accumulators:** Variables (like `totalBill`) used to sum up values during iteration.
* **Nested Structures:** Combining the `do-while` loop with a **Nested `switch`** statement for complex menus.
