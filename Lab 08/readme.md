## ✨ Lab Overview

This lab demonstrates the versatility of the `switch` statement for routing program execution based on an integer or character expression.

**Key Concepts Demonstrated:**

* **`switch` Statement:** Efficiently handles multiple possible execution paths.
* **`case` and `break`:** Defines and terminates each specific code block.
* **`default` Case:** Provides a fallback option for unmatched values.
* **Nested `switch`:** Using a `switch` statement inside another `switch` for multi-level menus.
