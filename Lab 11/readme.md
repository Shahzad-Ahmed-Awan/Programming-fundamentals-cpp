## ✨ Lab Overview

This lab demonstrates how to declare, initialize, traverse, and perform basic analysis on arrays.

**Key Concepts Demonstrated:**

* **Array Declaration & Initialization:** Defining fixed-size lists of data.
* **Traversal:** Accessing elements using the `for` loop and the array **index**.
* **Array Size Calculation:** Determining the number of elements in a static array.
* **Finding Extremes:** Locating the largest element in an array.
* **Reversing an Array:** Printing elements in reverse order.
