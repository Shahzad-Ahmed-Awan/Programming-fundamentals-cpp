## ✨ Lab Overview

This lab demonstrates how to implement complex, multi-level decision logic in C++ using structured conditional statements.

**Key Concepts Demonstrated:**

* **`if-else if-else` Chain:** Handling multiple possible conditions sequentially.
* **Nested `if` Statements:** Performing a second check only after a primary condition is met.
* **Logical Operators:** Combining conditions using `&&` (AND) and `||` (OR).
* **String Comparison:** Comparing user-input strings for login and roles.
* **I/O Formatting:** Using `iomanip` for formatted result displays.

To compile and execute this lab file, you will need a C++ compiler (e.g., `g++`).
